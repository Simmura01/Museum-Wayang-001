# Lantai 1 — Ruang 2 — Display

Ruangan ini (Koleksi Wayang Nusantara) berisi 9 display placeholder
(Display 7–15) yang dibuat otomatis oleh `buatDisplayPlaceholder()` di
`js/03-pameran-data.js`. Tambahkan foto lemari di sini dengan format
nama bebas (mis. `display7.jpeg`, `display8.jpeg`, ...) lalu update
path `img:` pada data displaynya.
