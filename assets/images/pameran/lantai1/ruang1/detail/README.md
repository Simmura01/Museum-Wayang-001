# Lantai 1 — Ruang 1 — Detail (foto close-up per wayang)

Foto close-up satu wayang saja, dipakai di modal detail saat hotspot
di-tap. Nama file mengikuti nama tokoh pada naskah voice-over
(`Naskah-VoiceOver-Wayang.md`) agar konsisten dengan audio.

| Nama file          | Tokoh              |
|---------------------|---------------------|
| ramawijaya.jpeg      | Ramawijaya          |
| rahwana.png          | Rahwana             |
| duryudana.jpeg       | Duryudana           |

> Display 2–5 di ruang ini masih memakai foto lemari (folder `display/`)
> sebagai foto detail sementara — belum ada foto close-up individual.
> Saat foto asli sudah ada, taruh di sini dan update path `img:` pada
> `js/03-pameran-data.js`.
