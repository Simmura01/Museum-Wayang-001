FOLDER GAMBAR ILUSTRASI ARTIKEL
================================

Letakkan gambar ilustrasi portrait di sini untuk kartu artikel Beranda.

Nama file yang diharapkan:
  - ilustrasi-sejarah.jpg     → untuk Artikel "Sejarah & Asal-Usul Wayang Nusantara"
  - ilustrasi-unesco.jpg      → untuk Artikel "Wayang & Pengakuan UNESCO 2003"
  - ilustrasi-pelestarian.jpg → untuk Artikel "Melestarikan Wayang: Warisan Budaya"

Panduan gambar:
  - Format: JPG atau PNG
  - Ukuran ideal: 300 x 400px (portrait / vertikal)
  - Objek utama sebaiknya di bagian atas (karena ditampilkan 110px tinggi)
  - Gambar akan di-crop otomatis dengan object-fit: cover
  - Jika file tidak ada, kartu akan menampilkan emoji sebagai fallback
